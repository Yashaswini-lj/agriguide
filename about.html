ABOUT THE PROJECT

AGRIGUIDE

A crop recommendation website built with HTML, CSS, JavaScript, Python, Flask, and SQLite.

How recommendations work

The farmer selects soil type, growing season, and expected weather. Python compares these selections with predefined crop rules and ranks crops by how well their conditions match. No AI, machine learning, trained model, or scikit-learn is used.

Website technologies

HTML structures the pages, CSS styles the interface, JavaScript supports browser interactions, Flask handles requests and recommendations, and SQLite stores accounts and prediction history.

Project limitation

The suggestions are based on general predefined rules and are for educational guidance. Actual suitability also depends on local climate, soil testing, irrigation, crop variety, and regional farming practices.

Future improvements

The rule list can be reviewed with local agriculture experts and updated for regional crops, Kannada language support, and verified local farming guidance.
